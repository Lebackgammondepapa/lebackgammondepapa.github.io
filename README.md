# Backgammon

Backgammon nacre et marbre bleu : contre l'ordinateur (3 niveaux), à deux sur le même appareil, ou en ligne avec un ami grâce à un code à 4 lettres.

**Jouer : https://tombrullefert-droid.github.io/le-backgammon-de-papa/**

Sur iPhone ou iPad : ouvrir le lien dans Safari, puis Partager → « Sur l'écran d'accueil » pour l'avoir en plein écran comme une application.
